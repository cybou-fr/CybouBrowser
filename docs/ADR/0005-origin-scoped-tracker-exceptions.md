# ADR 0005 — Временные исключения для трекеров по origin в профиле с правдивым UI

**Статус:** принято (заменяет ADR 0004).

## Контекст

В QtWebEngine 6 перехват запросов `QWebEngineUrlRequestInterceptor` на уровне профиля не содержит идентификатора вкладки (`tabUid`) или страницы. Поле `firstPartyUrl` возвращает видимый URL (`GetVisibleURL()`) активного WebContents. Перехватчик на уровне страницы (`getPageInterceptor`) в QML `WebEngineView` не экспонирован.

Предыдущая схема (ADR 0004) изолировала страницу в отдельном off-the-record профиле, что приводило к потере сессионного контекста (cookies, storage, авторизация), из-за чего исключение ломало сценарии, ради которых его включали. Попытка применить исключение «на месте» без привязки к origin вызывала рассогласование между реальным поведением фильтра и отображением в UI (соседние вкладки того же origin не видели исключение, а при включении в другой вкладке состояние затиралось).

## Решение

1. **Область действия — origin в профиле (`TrackerExceptionRegistry`):**
   Исключение предоставляется для конкретного origin (`https://example.com`) в текущем профиле. При этом сохраняются cookies и авторизация сайта.
2. **Владелец и жизненный цикл:**
   Исключение принадлежит вкладке-владельцу, которая его запросила. Исключение действует, пока вкладка-владелец остаётся на том же origin (`retainForOwner`). При уходе владельца на другой origin (`about:blank` или другой домен) или закрытии вкладки-владельца (`releaseTrackerOwner`) исключение отзывается.
3. **Правдивость UI (Truthful Observability):**
   Поскольку на уровне сетевого фильтра профиля запросы всех вкладок одного origin обрабатываются одинаково, все вкладки этого origin честно отображают активное состояние исключения в панели Network и могут выполнить его отзыв.
4. **Безопасность:**
   - Строгий HTTPS и запрет учетных данных в URL (`embedded-credentials`) не отменяются.
   - Межсайтовая изоляция сохраняется (запросы с других origin блокируются).
   - Никаких постоянных правил: состояние хранится только в памяти сессии.
