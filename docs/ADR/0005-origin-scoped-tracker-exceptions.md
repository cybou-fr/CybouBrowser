# ADR 0005 — временные tracker exceptions по origin

**Принято и существует в коде 0.3.0-alpha.2.** Основные компоненты: `TrackerExceptionRegistry`, сетевой interceptor, C++/QML Network-карточка.

QWebEngine URL interceptor обрабатывает запросы на уровне **профиля** и не предоставляет достоверную привязку каждого запроса к вкладке. Поэтому scope temporary tracker exception — **HTTPS origin в текущем профиле**, а не отдельная вкладка.

- Включение — исключительно действие пользователя в Network-карточке.
- Обычные cookies/авторизация остаются на месте; временный профиль **не создаётся**.
- Исключение имеет вкладку-владельца, действует пока владелец остаётся на origin, завершается при уходе/закрытии владельца или ручном revoke.
- Другие вкладки этого origin отражают реальное общее исключение; другие origin не получают его.
- HTTPS strict, URL credentials restriction и другие политики не выключаются.
- Событие `pass` означает решение фильтра, но не успешную сетевую загрузку.

**Отдельный механизм HTTP consent** открывает точный HTTP URL во временном off-the-record профиле; не смешивать два пути.

Квалификация до 1.0: concurrency, закрытие владельца, rejected navigation, redirects, normal/private, revoke и изменение origin — [TEST_PLAN](../TEST_PLAN.md).
