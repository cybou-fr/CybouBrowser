# ADR 0008 — доказательная квалификация версий

**Принято. Текущий исходный номер 0.3.0-alpha.1. Публичного релиза нет.**

1. Номер версии относится к **верифицированной стадии разработки**, а не количеству реализованных функций.
2. Первый публичный стабильный релиз — **1.0.0** для Windows x64 только после всех release gates.
3. Каждое применимое требование **OWASP ASVS 5.0.0** и каждый тестовый ID **OWASP WSTG 4.2** должны быть инвентаризированы, классифицированы и подтверждены результатом или рассмотренным `not_applicable`. OWASP Top 10:2025, SCVS и SAMM рассматриваются по назначению. Desktop browser-specific тесты дополняют OWASP.
4. Результат всегда относится к **конкретному source SHA, binary SHA-256, окружению, тесту и logfile**. Отсутствующее/непроверенное доказательство не превращается в PASS.
5. Изменения вносятся **непосредственно в `main`**. CI не обязателен до появления инфраструктуры; локальный fail-closed gate обязателен.
6. Никаких сторонних расширений и привилегий коммерческим партнёрам ([ADR 0006](0006-no-third-party-extensions.md), [ADR 0007](0007-selectable-cloud-services.md)).

Система проверки уже представлена `tools/security/owasp_gate.py` и `tests/security`, но OWASP coverage/mapping и реальное подтверждение всех требований **ещё не завершены**. Текущий статус 1.0.0 — **NO-GO**.
