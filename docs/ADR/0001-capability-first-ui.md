# ADR 0001: capability-first UI

Accepted direction, 16.10.2026. Eleven visible controls share one navigation row with the compact address. Explicit user corrections forbid a separate capability row and a fixed narrow address: the address fills all remaining space, with capability controls on the right. 34px icon slots preserve all controls at 820px. Hover only informs; a click grants a valid request or changes a supported reversible policy. Category-only menus, Always Allow and user-facing ASK are rejected because they hide control and restore persistent origin trust.
