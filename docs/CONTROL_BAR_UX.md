# Постоянная Control Bar

Control Bar встроена в единственную строку навигации рядом с компактным адресом. Выносить её в отдельную строку запрещено прямым уточнением пользователя от 16.10.2026. Все 11 иконок расположены с шагом 42 px, кнопки шириной 30 px разделены промежутками 12 px и доступны при минимальной ширине окна 820 px. Downloads/Menu расположены после Control Bar в этой же строке. Адрес занимает всё свободное место слева; Control Bar закреплена справа в той же строке. Фиксированная ширина адреса и пустой spacer запрещены последним уточнением пользователя. Ctrl+L выделяет полный URL, не скрывая возможности. Escape возвращает адрес страницы.

По последнему уточнению пользователя hover открывает стеклянную панель конкретной кнопки без клика: название, состояние, область/requester, ограничения наблюдения и доступные элементы управления. Обычные ToolTip у capability-кнопок удалены. Click выдаёт живой запрос либо переключает поддерживаемое поведение. Network открывает сведения **и реальные HTTP/tracker-only opt-in/revoke** во временном отдельном профиле на 60 секунд. Screen/Cookies объясняют ограничения: раздельного per-site Ads/Trackers backend пока нет.

Policy: серый unavailable, красный deny, цвет allow (не запись устройства), amber reload. Pending amber + !; recent event — отдельная точка. Accessible name включает политику и область. Tab и стрелки перемещают фокус, Space/Enter активируют кнопку. Reduced motion учитывается темой.

Смена вкладки закрывает детали и баннер. URL-change закрывает баннер, навигация отменяет pending permission. Fullscreen скрывает chrome согласно обычному режиму браузера.

Приёмка: 820×560, 1024×768, 1360×900, 1920×1080; DPI 100/150/200%; FR/RU; Ctrl+L + Escape; hover открывает правильную стеклянную панель; переход внутрь сохраняет её открытой; выход закрывает; соседняя иконка сразу меняет содержимое; клик по веб-странице доходит до Chromium. Скриншоты должны получаться из собранного приложения, не макетов.

Чувствительная кнопка без pending request сбрасывает временный доступ и перезагружает текущий URL в новой WebEngineView на том же месте; вкладки не добавляются. Стеклянная панель содержит пояснения и кнопки сброса/блокировки. Для pending grant кнопка фиксирует request ID при нажатии и использует этот ID при отпускании. Истечение lease уничтожает view и оставляет пустую вкладку с сохранёнными pinned/mute.

Открытие через 170 мс защищает от случайного пролёта курсора. Закрытие с задержкой 300 мс позволяет перейти с иконки внутрь панели через небольшой зазор. Hover панели отслеживается по всей поверхности, включая padding; во время работы с её кнопками панель остаётся открытой. Клик по самой capability сохраняет прямое действие. Минимальная ширина адреса 120 px обеспечивает приоритет 11 controls при 820 px; остальная свободная ширина по-прежнему принадлежит адресу.

Перед загрузками расположен вертикальный разделитель. Индикатор соединения слева от адреса превращается в кнопку HTTP: при заблокированной попытке она разрешает конкретный адрес на 60 секунд, при действующем исключении отзывает его, иначе показывает обычные сведения о соединении. Нажатие фиксирует токен вкладки/эпохи; отпускание не действует на другой контекст. Кнопка не вводит новую строку и не сокращает расстояния между capability controls.

Свободная область панели вкладок служит заголовком окна. Перенос начинается после системного порога движения мыши; одиночное нажатие не запускает перенос. Двойной клик разворачивает окно либо восстанавливает прежний размер. Перетаскивание самих вкладок сохраняет перестановку вкладок.

Оставшиеся краткие подсказки навигации и вкладок используют общий GlassToolTip: синий стеклянный градиент, скругление, тонкая синяя рамка, ограниченная ширина и перенос текста. Системные чёрные ToolTip с белой рамкой не используются. Capability controls по-прежнему открывают полноценные стеклянные панели. Библиотека (загрузки, избранное, история) и настройки начинаются под header и ограничены высотой contentItem; общий затемняющий слой окна отключён. При открытии одной боковой панели другая закрывается.

## UX следующего этапа: улучшение поведения, НЕ переработка компоновки

**Неприкосновенная геометрия:** существующая одна строка; 11 видимых отдельных кнопок; 42 px между центрами, 30 px сами кнопки; address min 120 px, всё дополнительное свободное место принадлежит адресу; Downloads/Menu справа за разделителем. Ctrl+L и мышь редактируют полный адрес, не скрывая Control Bar. Ни второй строки, ни категориальных замен, ни сужения адреса до фиксированной ширины «ради панели».

**Неприкосновенный hover:** через 170 мс открывается большая стеклянная интерактивная карточка; её поверхность принимает курсор; переход на соседнюю иконку переключает карточку, закрытие через 300 мс; кнопки карточки настоящие и доступные. Plain GlassToolTip используется для других элементов chrome, **не вместо capability hover-панели**.

**Семантика цвета (запланирована, сегодня иначе):** сейчас `ControlBarIcon` окрашивает Allow с помощью `brandColor`; Camera красная при разрешении и блокировка тоже красная. Следующий этап отделяет policy и event. Default deny — нейтральный, live request — янтарный, temporary grant — спокойный зелёный, подтверждённый block — красный отдельный event-маркер, фильтр enabled — холодный бирюзовый. `ReloadRequired` и unknown имеют отдельные формы и текст. Не опираться на цвет без accessible name, focus/keyboard/reduced-motion.

**Сетевое управление (частично реализовано):** нынешняя Network-карточка уже предлагает одно 60-секундное tracker-only исключение для HTTPS-страницы с countdown и revoke; отдельный профиль не наследует cookies/cache и пересоздаёт документ. **Будущий этап** — две независимые категории Ads/Trackers внутри нынешней Network-карточки *после реализации реального классификатора*. Временное исключение ограничено site+tab+profile+epoch+TTL, с понятным Reload и точным Undo; никогда не глобальное отключение из карточки текущего сайта. Нет ложных per-tab счётчиков поверх profile-wide samples.

**Permission UX (planned):** в карточке честно показывать временный grant и что текущий 60-секундный expiry уничтожает документ. Предупреждение/явное продление рассматриваются только после испытаний безопасного media stop. Нельзя тайно продлевать доступ, сохранять Always Allow или просто скрыть fail-closed поведение.

**Приёмка:** сочетания pending/allow/blocked и hover во всех четырёх размерах, DPI 100/150/200%, FR/RU, reduced-motion; смена вкладки/навигации не позволяет stale popup применить чужую политику; сетевое исключение не влияет на peer tab; Network-карточка не обрывает взаимодействие с веб-страницей. План и проверки: [SECURITY_UX_EVOLUTION](SECURITY_UX_EVOLUTION.md), [TEST_PLAN](TEST_PLAN.md).
