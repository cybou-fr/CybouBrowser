# CYBOU — Control Bar UX

**Нормативное решение владельца продукта:** Control Bar постоянно находится **в одной существующей строке навигации**. Не выносить её в отдельную строку и не группировать её возможности в несколько значков.

## Геометрия

- 11 отдельных иконок всегда доступны в той же строке, что и адрес.
- Шаг между иконками **42 px**, ширина самих кнопок **30 px**. Все должны оставаться видимыми при минимальном окне **820 px**.
- Адрес слева имеет minimum **120 px** и занимает **всю оставшуюся ширину**, а не искусственно фиксированный маленький слот. Ни адрес, ни Ctrl+L не должны вытеснять controls.
- После Control Bar — вертикальный разделитель; **Downloads** и **Menu** визуально отделены, но находятся **в той же строке**.
- `Ctrl+L` и клик по адресу позволяют увидеть/редактировать полный URL; `Escape` возвращает компактный вид. Не создавать дополнительную панель во время редактирования.

## Взаимодействие — НЕ заменять обычным tooltip

**Hover открывает большую интерактивную стеклянную карточку**, без клика по capability: title, текущий effective state, scope, requesting origin при наличии, основание/ограничения наблюдения и допустимые действия. Открытие через 170 мс, закрытие с задержкой 300 мс. Курсор может перейти внутрь карточки; при перемещении к соседней кнопке содержание своевременно заменяется. Клик по самой иконке выполняет настоящее поддерживаемое действие, не просто открывает пояснение.

У кнопок навигации/вкладок — отдельный стилизованный `GlassToolTip`. У capability controls — **именно интерактивная карточка**. Клавиатурные Tab/стрелки и Space/Enter, accessible labels и reduced motion обязательны для проверки.

## Что сейчас происходит при действиях

- Pending native permission подсвечивает нужную кнопку; клик разрешает именно действующий request ID, а молчание отклоняет запрос. Без пользовательского ASK и Always Allow.
- JS/storage/popups переключаются непосредственно; если требуется reload, отображается исходный контекст и корректный Undo.
- Screen без chooser и Cookies с настройкой уровня профиля должны честно показывать пределы прямого действия.
- **Network-карточка уже содержит** данные сетевого фильтра, категории событий, подтверждённые блокировки, HTTP temporary consent/revoke и tracker-only temporary exception/revoke с отображением состояния. Полноценные независимые Ads/Trackers controls — отдельная будущая задача. Никаких глобальных выключателей защиты в site-card.
- Отзыв временного permission/сетевого контекста может завершить текущую страницу; последствия показывать честно, без выдуманного статуса stop-recording.

## Отдельно о визуальных сигналах

**Текущая реализация** частично смешивает `brandColor` capability и effective policy: красный может обозначать и разрешённую Camera, и блокировку. **Следующее изменение (planned):** разделить PolicyPresentation и EventPresentation. Default closed — нейтральный; pending — янтарный; grant — спокойный зелёный; confirmed blocked — красный event marker; enabled filter — сине-бирюзовый. Форма/подпись дополняют цвет, и grant не выдаётся за использование устройства. Точные критерии — в [SECURITY_UX_EVOLUTION](SECURITY_UX_EVOLUTION.md).

## Граница с облачным launcher новой вкладки

**«Почта» и 3×3 переключатель облачных приложений находятся в правом верхнем углу NewTabPage, а не в браузерной навигационной строке.** Launcher по клику раскрывает вниз отдельную интерактивную панель Dark Glass с действительным смешанным набором сервисов (общий провайдер + индивидуальные overrides). Это не hover popover capability. Браузерные 11 иконок, омнибокс, геометрия и поведение Control Bar неизменны. Нельзя накрывать browser-owned controls. См. [ADR 0007](ADR/0007-selectable-cloud-services.md).

## Приёмка

Проверять **820×560**, 1024×768, 1360×900, 1920×1080, DPI 100/150/200%, FR/RU, hover pointer corridor, keyboard, Ctrl+L/Escape, реальную работу карты/панелей и передачу клика в страницу Chromium. Если скриншоты нужны, снимать **из запущенного приложения**, а не рисовать макеты.

Chrome вне Control Bar: свободная область вкладок принимает drag окна; двойной клик разворачивает/восстанавливает. Bookmarks, downloads, history и settings выдвигаются **под header**, не накрывая controls и не затемняя весь browser chrome. Правила поведения см. в [CAPABILITY_CONTRACT](CAPABILITY_CONTRACT.md).
