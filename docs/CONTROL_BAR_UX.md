# Постоянная Control Bar

Control Bar встроена в единственную строку навигации рядом с компактным адресом. Выносить её в отдельную строку запрещено прямым уточнением пользователя от 16.10.2026. Все 11 иконок имеют ширину 34 px и доступны при минимальной ширине окна 820 px. Downloads/Menu расположены после Control Bar в этой же строке. Адрес занимает всё свободное место слева; Control Bar закреплена справа в той же строке. Фиксированная ширина адреса и пустой spacer запрещены последним уточнением пользователя. Ctrl+L выделяет полный URL, не скрывая возможности. Escape возвращает адрес страницы.

Hover показывает только tooltip конкретной кнопки: название, состояние, область/requester, ограничения наблюдения. Click выдаёт живой запрос либо переключает поддерживаемое поведение. Network/Screen/Cookies могут открыть сведения, так как единственного site-scoped действия backend пока не поддерживает.

Policy: серый unavailable, красный deny, цвет allow (не запись устройства), amber reload. Pending amber + !; recent event — отдельная точка. Tooltip plain text; accessible name включает политику и область. Tab и стрелки перемещают фокус, Space/Enter активируют кнопку. Reduced motion учитывается темой.

Смена вкладки закрывает детали и баннер. URL-change закрывает баннер, навигация отменяет pending permission. Fullscreen скрывает chrome согласно обычному режиму браузера.

Приёмка: 820×560, 1024×768, 1360×900, 1920×1080; DPI 100/150/200%; FR/RU; Ctrl+L + Escape; hover не открывает shared popover; клик по веб-странице доходит до Chromium. Скриншоты должны получаться из собранного приложения, не макетов.

Чувствительная кнопка без pending request сбрасывает временный доступ и перезагружает текущий URL в новой WebEngineView на том же месте; вкладки не добавляются. Tooltip сообщает о перезагрузке и сбросе. Для pending grant кнопка фиксирует request ID при нажатии и использует этот ID при отпускании. Истечение lease уничтожает view и оставляет пустую вкладку с сохранёнными pinned/mute.
