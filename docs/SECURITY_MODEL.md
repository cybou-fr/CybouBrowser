# Модель безопасности

## Граница доверия
Веб-страница и iframe недоверенные. Browser-owned QML получает QWebEnginePermission и разрешает только действительный объект запроса. Координатор пока находится в Main.qml; выделение в отдельный C++ PermissionCoordinator запланировано.

Оба профиля используют AskEveryTime. Это механизм движка, не диалог пользовательского интерфейса. Controller не выдаёт grants через queryPermission. Старые controlPolicies удаляются; новые поведенческие исключения хранятся в памяти отдельно по tab UID и origin. Запреты не означают остановку уже работающего устройства.

## Жизненный цикл
Одновременно ожидает один запрос окна; неподдерживаемые и фоновые запросы отклоняются. Timeout 15 секунд. Проверяются объект вкладки, профиль, top origin и requesting origin. Смена вкладки, навигация основного фрейма, закрытие вкладки и окна отменяют ожидание. Навигация/закрытие уничтожают документ с доступом; минутный таймер переводит вкладку на about:blank. Новый grant продлевает общий таймер вкладки: независимые leases по запросам ещё не реализованы.

## Сеть
HTTPS strict включён по умолчанию; interceptor запрещает HTTP и ws в строгом режиме. Старые пользовательские настройки HTTPS пока сохраняются. Временного безопасного исключения HTTP ещё нет; прежний host-wide fallback существует только при вручную выключенном strict. Это известный разрыв с целевой моделью, а не выполненный этап.
Статический suffix-list блокирует часть сторонних сетевых запросов. Сетевые события имеют профильную область: firstParty не доказывает конкретную вкладку. Храним только origin, firstParty origin, тип, время, результат и причину; никаких path/query/headers/bodies.

## Не гарантируется
Нет достоверного датчика использования camera/mic, доказанной per-tab proxy изоляции, оценки вредоносности неизвестного сайта и полного отзыва всех native разрешений без выгрузки документа. AskEveryTime и iframe/media lifecycle необходимо проверить на реальных сайтах Qt 6.12.
